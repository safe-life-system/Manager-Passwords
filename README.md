### Цель проекта
Локальный менеджер паролей с авторизацией, шифрованием данных, генерацией юезопасных паролей и открытым исходным кодом.

### Задачи
- [x] Авторизация с помошью пароля;
- [x] Локальное хранение и шифрование загруженных паролей;
- [x] Создание пароля;
- [x] Генерация безопасного пароля;
- [x] Добавление/удаление/редактирование паролей;
- [x] Импорт/экспорт паролей в формате CSV;
- [x] Поиск по сохраненным паролям;
- [ ] Кроссплатформенность (Windows, Linux, Android, iOS);
- [ ] Синхранизация с телефоном (по желанию);
- [ ] Автоматическое создание учетной записи на доступных площадках и сервисах (по желанию).

#Запуск кода проекта
